# Frontend Documentation

This is the front matter documentation for the project.

## Overview
The frontend is built with React, TypeScript, and uses the shadcn/ui component library for consistent styling.

## Key Components
- **Index.tsx**: Main landing page
- **NotFound.tsx**: 404 error page
- **MadeWithDyad.tsx**: Attribution component

## Styling
All styling is done using Tailwind CSS with a custom design system based on CSS variables.
